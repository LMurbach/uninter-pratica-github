# Prática de GitHub — Uninter

Exercício acadêmico da **Aula 3 — Desenvolvimento Colaborativo**, da disciplina **Ferramentas de Desenvolvimento Web**, no curso de Gestão da Tecnologia da Informação da Uninter.

## Objetivo da atividade

Praticar a criação de um repositório no GitHub, o envio dos arquivos e a publicação de um site com o GitHub Pages.

## Minha participação

O site sobre Curitiba **foi fornecido pronto no material da aula**. Minha participação foi:

- Criar o repositório no GitHub.
- Enviar os arquivos disponibilizados na aula.
- Publicar o site pelo GitHub Pages.

O desenvolvimento do site do zero não faz parte da minha autoria. Este repositório registra uma prática acadêmica de uso do GitHub e publicação na web.

## Visualizar o site

[Abrir o exercício no GitHub Pages](https://lmurbach.github.io/uninter-pratica-github/)

Para visualizar localmente, baixe os arquivos do repositório e abra `index.html` em um navegador, mantendo a estrutura de pastas. A página utiliza HTML, CSS, Bootstrap e jQuery presentes no material recebido; isso não representa uma declaração de domínio dessas tecnologias.

## Estrutura dos arquivos

- `index.html`: página sobre Curitiba fornecida na aula.
- `estilo.css`: estilos do material.
- `img/`: imagens utilizadas na página.
- `bootstrap/` e `jquery.js`: bibliotecas incluídas no material.
